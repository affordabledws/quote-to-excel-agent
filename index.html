Quote-to-Excel Master Rules

Updated after workbook formatting and row-size testing

Exact template formatting

Use the attached workbook as output and preserve it exactly. Never add, remove, recolor, or restyle rows/cells. Preserve sheets, table, headers, column order, colors, fills, fonts, borders, widths, row heights, number formats, formulas, and settings. If anything differs, return the workbook and identify the formatting difference.

Headers

First HEADER is the quote/project name, e.g. MENS ET MANUS LLC - COPY OF 29 HENRY. The general header uses natural lines:

UNITED VINYL WINDOWS AND GLASS AND SASH
1800 REPLACEMENT SERIES
WHITE EXTERIOR
WHITE INTERIOR
LOW-E7-N, SINGLE STRENGTH, ARGON
WHITE HARDWARE, DOUBLE LOCKS
NO SCREENS

The screen line is mandatory: colored FULL SCREENS, colored HALF SCREENS, or NO SCREENS. Never state screen material.

Original order/PO and notes

Always add explicit ORIGINAL ORDER NUMBER/PO to the header, or only to its row if item-specific. Read other note text but do not add it automatically. Return the workbook, quote the note, and ask whether to add it. If yes, update and return a new download.

Rows and sizes

First line = actual item type/position + short series + operation. Then only differences from header. Last lines:

UNIT CODE: [CODE] only when explicit
UNIT SIZE: 33.25" x 61.25"
ROUGH OPENING: 33.5" x 61.5" [operation/handing only when needed]

Never use “-in”. Do not add OPERATING/VENTING or repeat operation after RO for SINGLE HUNG, DOUBLE HUNG, FIXED, or similar products already clear in the first line. Add specific operation/handing for sliders, casements, doors, mixed assemblies, and other configurations where handing matters.

Rates and totals

Store actual Rate values rounded to exactly two decimals, never floating-point artifacts. If hidden fractional cents cause a quote/Excel difference, do not force a match. Always return the workbook and state the exact LESS/MORE difference.

Other rules

Keep exact PDF order. Separately listed items remain separate rows. Tax is No on every row. Correct OCR only in location names. Preserve reference restrictions, mapping rules, grouping rules, grille full-assembly counts, TOP/BOTTOM order, and filename cleanup.
