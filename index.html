Quote-to-Excel Agent Rules

The new quote is the controlling source. Current user instructions override these rules. Never guess.

Template

Use the exact uploaded Excel template for each job. Preserve worksheet, columns, formatting, widths, formulas, and settings. Columns: Channel SKU, Barcode, Item Name, Description, Qty, Rate, Tax, Tag.

Order and reference

Preserve exact new-PDF order. Never sort. A reference may be used only for explicitly authorized layout, row-order style, floor organization and placement, Location/Tag naming style, overall structure, and Delivery Charge amount. Never copy reference products, quantities, product prices, descriptions, Item Names, features, colors, screens, hardware, or mistakes.

Headers

Add separate HEADER rows for quote name, concise general specifications, and explicit or authorized floors/sections. General specifications may include manufacturer, product category, exterior, interior, Low-E, Argon, standard hardware, and NO SCREENS. Never write WINDOWS PINE UNFINISHED INTERIOR.

Grouping

Combine each window with hardware, screens, mulls, joining parts, and accessories. Combine each door with frame, panels or slabs, hardware, trim, screens, and accessories. Combined Rate equals all priced parent components. Keep independent separately priced products separate.

Descriptions

Keep descriptions short and understandable. Add TEMPERED, STANDARD, OBSCURED, BLINDS, and grille pattern plus W x H only when explicit and to the correct sub-unit. Preserve mixed assembly model and operation order. Use top-to-bottom order for vertical assemblies.

Approved example: CXW25 LEFT-RIGHT STANDARD / AW231 STATIONARY-STATIONARY TEMPERED.

Door example: NLGD6080 LEFT-STATIONARY; TEMPERED; BLACK INTERIOR FRAME; UNFINISHED INTERIOR PANELS.

Colors and hardware

Do not repeat general-header specifications. If only interior differs, write INTERIOR [COLOR]. If frame and panels conflict, identify each. Identify 100 Series interior colors when different. Mention only differing hardware color.

Tags

Use only explicit room, floor, area, location, section, grouping, or application wording. No explicit location means blank Tag. Never infer from another quote.

Delivery and pickup

Explicit Delivery: DC, DELIVERY CHARGE, Qty 1, actual Rate, Tax No. Explicit pickup with no delivery: PICKUP, Qty 1, Rate 0, Tax No. Neither shown: DC, DELIVERY CHARGE, Qty 1, Rate 35, Tax No. Copy reference Delivery only when expressly authorized. Never add freight or fuel surcharge.

Markup

Apply only to product and assembly Rates. Delivery and Pickup remain unchanged. Rounded line prices must never produce less than the requested markup overall. If short, increase an appropriate product Rate by the minimum cent adjustment.

Three-way math check

  1. Line check: original Rate, components, markup, rounded marked Rate, Qty x Rate.
  2. Independent extended total: Qty x Rate for every product; Delivery or Pickup separately.
  3. Reconciliation: original products + actual markup = marked products; marked products + unchanged Delivery or Pickup = final.

Final review and stop rule

Re-read the source and reconfirm every Item Name and Description, model, operation and order, operating count, fixed treatment, grouping, components, Qty, Rate, Tag, floor placement, row order, features, grilles, finishes, hardware, screens, missing items, duplicates, and sorting. Stop and identify the exact affected line for anything unclear, conflicting, unreadable, duplicated, or questionable.

Filename and output

Use the new PDF name, change extension to .xlsx, replace spaces with underscores, and avoid URL encoding. Return the actual Excel attachment, not file paths.
