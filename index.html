Quote-to-Excel Master Rules and Examples

Approved after first full testing round

Header style

Use the same natural style for every manufacturer. Include exact company, material, all applicable product categories, all series on one line, exterior, interior, glass without intercept spacer, common hardware, and screen color/coverage. Example:

UNITED VINYL WINDOWS AND GLASS AND SASH
1800 REPLACEMENT SERIES
WHITE EXTERIOR
WHITE INTERIOR
LOW-E7-N, SINGLE STRENGTH, ARGON
WHITE HARDWARE, DOUBLE LOCKS
WHITE FULL SCREENS

For vinyl only, include REPLACEMENT or NEW CONSTRUCTION when explicit. Never include Unit Size or Rough Opening in the header.

Row style

Every row begins with short series plus operation/type. Add explicit unit code on that line when present. A regular complete-unit row uses its normal product operation/type only:

1800 SINGLE HUNG
UNIT SIZE: 35.5" x 64"
ROUGH OPENING: 36" x 64.5" SINGLE HUNG

For every non-regular item, state whatever the item actually is, including its position or description when explicit. The rule applies to any item type, not only the examples below:

1800 SINGLE HUNG, SASH ONLY - BOTTOM
1800 SINGLE HUNG, GLASS ONLY - TOP
1800 SINGLE HUNG, MULL
1800 SINGLE HUNG, PART
1800 SINGLE HUNG, FRAME
1800 SINGLE HUNG, SCREEN
1800 SINGLE HUNG, HARDWARE
1800 SINGLE HUNG, ACCESSORY

Never label a regular complete unit as a non-regular item. If a row matches the header, include only the base first line, explicit unit code/non-regular type if applicable, Unit Size, and Rough Opening. If different, insert only explicit differences on separate lines before the sizes. Never repeat header data.

Core rules

Keep exact PDF order. Separately listed items stay separate rows. Tax is No on every row. Correct OCR only in location names. Rates use exactly two decimals. Hidden fractional-cent differences must not be forced to match; always return the workbook and report the exact LESS/MORE difference. Reference use is limited to layout, row order, floor placement, and Tag naming style.
