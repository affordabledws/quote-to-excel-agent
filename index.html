Quote-to-Excel Master Rules and Examples

Approved after first full testing round

First header

The first HEADER is always the quote/project name from the new quote. Example:

MENS ET MANUS LLC - COPY OF 29 HENRY

The general-description header is separate.

General header style

Use the same natural style for every manufacturer. Include exact company, material, applicable product categories, all series on one line, exterior, interior, glass without intercept spacer, common hardware, and screen color/coverage:

UNITED VINYL WINDOWS AND GLASS AND SASH
1800 REPLACEMENT SERIES
WHITE EXTERIOR
WHITE INTERIOR
LOW-E7-N, SINGLE STRENGTH, ARGON
WHITE HARDWARE, DOUBLE LOCKS
WHITE FULL SCREENS

For vinyl only, include REPLACEMENT or NEW CONSTRUCTION when explicit. Never include Unit Size or Rough Opening in the header.

Original order, PO, and other notes

If ORIGINAL ORDER NUMBER/PO appears, always add it to the general header on its own line, for example ORIGINAL ORDER NUMBER/PO: #1642336. If it differs by item, put the applicable value only in that row.

Read the remainder of the note, such as CUSTOMER NOW WANTS LOW E7N GLASS, but do not automatically add non-PO note text. Return the completed workbook, quote the note to the user, and ask whether to add it. If the user says yes, update the workbook and return a new download.

Row style

The first thing in each row is the actual item type and explicit position, then the short series and operation:

GLASS - TOP ONLY 1800 SINGLE HUNG
SASH - BOTTOM ONLY 1800 SINGLE HUNG
MULL 1800 SINGLE HUNG
PART 1800 SINGLE HUNG
SCREEN 1800 SINGLE HUNG
WINDOW 1800 SINGLE HUNG

Use whatever item type the quote actually identifies. Do not limit non-regular items to glass or sash. Then show only explicit differences from the header.

The last things in every row must be:

UNIT CODE: [CODE]   only when explicit
UNIT SIZE: [WIDTH] x [HEIGHT]
ROUGH OPENING: [WIDTH] x [HEIGHT] [OPERATION]

If no code exists, omit UNIT CODE. Never repeat common header specifications.

Core rules

Keep exact PDF order. Separately listed items stay separate rows. Tax is No on every row. Correct OCR only in location names. Rates use exactly two decimals. Hidden fractional-cent differences must not be forced to match; always return the workbook and state the exact LESS/MORE difference. Reference use is limited to layout, row order, floor placement, and Tag naming style.
