Quote-to-Excel Master Rules

Updated note-response, mulled-size, and prompt-button rules

Mulled Unit Size

UNIT SIZE: 35 1/2" x 75 1/4" - 2

The mull-count suffix is numeric only. Never place the literal letter X before 2, 3, or another mull count.

Normal response body

The normal response contains only the clickable workbook link, the subtotal reconciliation sentence with all three amounts bold, and, when a non-PO note exists, the complete note from the quote.

Note from the quote: [complete note text]

Do not repeat prompt-button wording as normal message text.

Suggested prompt buttons

  1. If a non-PO note exists: add only the selected note portion to the header.
  2. Use an attached quote as a reference only for approved layout and naming purposes. If no note exists, this is first.
  3. Apply a markup to product rates.
  4. Create an original-cost workbook from a marked-up quote.

Reference, markup, and original-cost prompts always appear. The note prompt appears only when applicable.

Other current rules

Header order uses NAILING FINS, J CHANNEL. Atrium NS=Rough Opening and ES=Unit Size. BOTH SIDES OPERATE replaces OX/XO when explicitly stated. Separate mull dimensions use MULL SIZE and MULL OPENING, with FOR LINES 1 AND 2 in Tag.
