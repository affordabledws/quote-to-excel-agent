Quote-to-Excel Master Rules

Updated after spacing, rate-storage, and floor-header testing

Template formatting

Preserve the attached workbook exactly. Never add, remove, recolor, or restyle rows/cells, including alternating row colors. If formatting differs, return the workbook and identify the exact difference.

Headers

First HEADER is the quote/project name. Create one general-description HEADER. Create HEADER rows only for floors, such as 1ST FLOOR and 2ND FLOOR. Never create room/location headers. Rooms such as Front room, Kitchen, Back room, and Bathroom belong only in Tag.

List only product categories actually in the quote. Do not add WINDOWS when the quote contains only GLASS and SASH. General-header example only:

UNITED VINYL GLASS AND SASH
1800 REPLACEMENT SERIES
WHITE EXTERIOR
WHITE INTERIOR
LOW-E7-N, SINGLE STRENGTH, ARGON
WHITE HARDWARE, DOUBLE LOCKS
NO SCREENS
_
ORIGINAL ORDER NUMBER/PO: #1642336

Always include the correct screen statement.

Row layout and spacing

Never write LINE #, UNIT LINE, or UNIT LINES. Write UNIT CODE only if the quote explicitly labels a real Unit Code.

1800 SINGLE HUNG, GLASS - TOP ONLY

UNIT SIZE: 33.25" x 61.25"
TOP TEMPERED, DOUBLE STRENGTH

ROUGH OPENING: 33.5" x 61.5"
_

Use exactly one blank line after the first line and exactly one blank line before ROUGH OPENING. Bathroom and every other row use this same layout. Features come after UNIT SIZE. Use inch marks, never “-in”. Do not add operating/venting for Single Hung, Double Hung, Fixed, or similar products. Add needed handing for sliders, casements, doors, and mixed units.

Rates

Store actual Rate values rounded to exactly two decimals, not merely formatted to display two decimals. Never store floating-point artifacts such as 86.09999999999999 or 97.23999999999999. Read back every completed Rate before delivering the workbook.

Examples

All names, series, types, positions, values, sizes, colors, and features shown here are examples only. Scan each new quote line by line and use only its actual explicit information.
