Quote-to-Excel Master Rules

Updated after line-number and row-layout testing

Exact template

Preserve the attached workbook exactly. Never add colors, fills, styles, borders, or other formatting. Report any difference.

Headers

MENS ET MANUS LLC - COPY OF 29 HENRY

General header:

UNITED VINYL WINDOWS AND GLASS AND SASH
1800 REPLACEMENT SERIES
WHITE EXTERIOR
WHITE INTERIOR
LOW-E7-N, SINGLE STRENGTH, ARGON
WHITE HARDWARE, DOUBLE LOCKS
NO SCREENS
_
ORIGINAL ORDER NUMBER/PO: #1642336
CUSTOMER NOW WANTS LOW E7N GLASS

Screen line is mandatory. Add explicit PO automatically. Ask before adding other note text.

Examples are not job data

Every displayed company, series, operation, item type, position, code, size, color, and feature is an example only. For every new job, scan and verify the actual quote line by line and use only values explicitly shown in that quote. Never copy example values or infer missing details.

Rows

Never add a separate WINDOW/SASH/GLASS line and never write UNIT LINE or UNIT LINES. First line is series + operation/type. If non-regular, add actual item type on that same line:

1800 2 LITE SLIDER, SASH - LEFT ONLY

UNIT SIZE: 53.75" x 37.75"
LEFT OPERATING (XO)
TOP TEMPERED, DOUBLE STRENGTH

ROUGH OPENING: 54" x 38"
_

Never write LINE #, UNIT LINE, or UNIT LINES. Write UNIT CODE only when the quote explicitly labels a real Unit Code. Otherwise omit it. Rows repeat no header values.

Other rules

Use inch marks, never -in. Do not add OPERATING/VENTING for Single Hung, Double Hung, Fixed, etc. Add needed handing for sliders, casements, doors, and mixed units. Tax is No on every row. Rates are stored at exactly two decimals. Correct OCR only in location names. Return the workbook even when totals differ.
