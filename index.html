[GRILLE LINE IF PRESENT]

_

For every vinyl New Construction quote, put NAILING FINS on the same line after J CHANNEL. Hardware has its own line. The complete explicit screen name and material go on a separate line directly below Hardware. Include screen color only when explicit.

Unit Size rule

Omit UNIT SIZE whenever the source does not explicitly provide a separate actual Unit Size. Never infer Unit Size from Customer Size, Nominal Size, Opening Size, or Rough Opening. This applies to all manufacturers.

Atrium NS and ES

NS means Nominal Size and becomes ROUGH OPENING. ES means Exact Size and becomes UNIT SIZE. If only NS appears, write ROUGH OPENING and omit UNIT SIZE. If ES appears, write UNIT SIZE. If both appear, include both correctly.

Atrium operation notes

If an Atrium line explicitly says BOTH SIDES OPERATE, write that note instead of OX/XO. Do not write both.

Separate mull

450 TWIN MULL ONLY

MULL SIZE: 0" x 71 1/2"
MULL OPENING: 1/2" x 72"
_

Put FOR LINES 1 AND 2 in Tag as the location/note. Do not place it between MULL SIZE and MULL OPENING. Do not label mull measurements Unit Size or Rough Opening.

Other rules

Grilles immediately follow Glass and are counted per individual unit. Preserve complete Tags/window IDs and notes. Preserve template formatting. Tax is No on every row. Store Rates at exactly two decimals. Examples are never job data.
