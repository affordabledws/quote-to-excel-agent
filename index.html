Quote-to-Excel Master Rules

Updated workbook and final-response rules

Header order

ATRIUM VINYL WINDOWS
NEW CONSTRUCTION, 450 SERIES
PAINTED BLACK EXTERIOR, WHITE INTERIOR
CLEAR, STANDARD LOW-E, ARGON
[GRILLE LINE IF PRESENT]
NAILING FINS, J CHANNEL
FACTORY MULL, [COMMON MULL SIZE]
WHITE HARDWARE, 2 LOCKS
EXTRUDED FULL SCREEN, STANDARD MESH
_

For vinyl New Construction, use NAILING FINS, J CHANNEL in that exact order. Screen description excludes SHIPPED SEPARATELY.

Mulled rows

Use suffixes exactly - 2, - 3, etc., never - X 2. Place UNIT SIZE before glass differences such as DOUBLE STRENGTH. Use only an explicit individual actual Unit Size.

Atrium notes

If BOTH SIDES OPERATE is explicit, use it instead of OX/XO and keep it out of Tag.

Separate mull

450 TWIN MULL ONLY

MULL SIZE: 0" x 71 1/2"
MULL OPENING: 1/2" x 72"
_

Put FOR LINES 1 AND 2 in Tag.

Final response

Return only the workbook link, subtotal reconciliation, and follow-up prompts in this exact order:

  1. If a non-PO header note exists: Add only this portion of the note to the header.
  2. Use the attached quote as a reference only for line layout, row order, and naming style.
  3. Apply a markup to the product rates.
  4. Create an original-cost workbook.

If no non-PO header note exists, the reference prompt appears first. The reference, markup, and original-cost prompts must always appear.
