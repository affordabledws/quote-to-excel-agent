Quote-to-Excel Master Rules

Updated single-row quote rules

Single-row quotes

If the entire source quote contains exactly one priced product row, create only one quote-name HEADER, one concise priced product row, and the required Delivery/Pickup row. Do not create a general-description HEADER or duplicate the product. This applies to every manufacturer and every item category.

[MODEL/ITEM TYPE]
UNIT SIZE: [EXPLICIT ACTUAL UNIT SIZE, ONLY IF PROVIDED]
[COLOR OR OTHER EXPLICIT SPECIFICATION]
PN: [PRODUCT NUMBER, WHEN PROVIDED]
_

Use the actual source wording for that manufacturer. Use PN: in the concise row. Omit Rough Opening unless needed or specifically requested. Leave Tag blank for None Assigned, Unassigned, N/A, Not Applicable, or similar placeholders.

Multi-row quotes

If more than one priced product row exists, use the normal general-header rules, exact PDF order, and only explicit source data.

Other current rules

Mulled Unit Size suffixes use numeric counts only, such as UNIT SIZE: 35 1/2" x 75 1/4" - 2. Header order uses NAILING FINS, J CHANNEL. Atrium NS=Rough Opening; ES=Unit Size. BOTH SIDES OPERATE replaces OX/XO when explicit. Separate mull measurements use MULL SIZE and MULL OPENING, with the line reference in Tag.

Final response

Return only the workbook link, reconciliation sentence, and complete quote note when applicable. Suggested prompts stay separate in this order: selected note portion if applicable, reference quote, markup, original-cost workbook.
