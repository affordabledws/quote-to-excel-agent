Updated Atrium formatting and final-response rules

Header

NEW CONSTRUCTION, 450 SERIES
PAINTED BLACK EXTERIOR, WHITE INTERIOR
CLEAR, STANDARD LOW-E, ARGON
[GRILLE LINE IF PRESENT]

WHITE HARDWARE, 2 LOCKS

_

Use ATRIUM VINYL WINDOWS, not a list of individual window types. Never include SHIPPED SEPARATELY in the screen description.

Mulled sizes

Suffixes must be exactly - 2, - 3, etc., never - X 2 or - X 3. Use only an explicit individual actual Unit Size. Never infer Unit Size from customer, nominal, opening, or rough-opening dimensions.

Atrium NS/ES and notes

NS=Nominal Size/Rough Opening. ES=Exact Size/Unit Size. If BOTH SIDES OPERATE is explicit, put that note in Description instead of OX/XO. Do not duplicate the note in Tag.

Picture windows

Do not add NO HARDWARE or NO SCREENS to fixed/picture rows merely because the header defaults apply to operating products. Omit those lines unless explicitly meaningful in the source.

Separate mull

450 TWIN MULL ONLY

MULL SIZE: 0" x 71 1/2"
MULL OPENING: 1/2" x 72"
_

Put FOR LINES 1 AND 2 in Tag.

Final response

Return only the workbook link, one subtotal reconciliation sentence with all three dollar amounts bold, and the applicable ready-to-use option prompts for selected header-note text, reference layout, markup, or reversing markup to original cost.
