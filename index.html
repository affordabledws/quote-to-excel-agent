Use one general-description HEADER cell with line breaks. For vinyl always state NEW CONSTRUCTION or REPLACEMENT. Grilles immediately follow Glass. Then frame/J-channel, common Mull type/size, and common Hardware/Screens. Rows show only differences. If screen color is unspecified, omit it. Never say “on operating units.”

Mulled rows

450 DOUBLE HUNG - 2

UNIT SIZE: 35 1/2" x 75 1/4" - 2

ROUGH OPENING: 72" x 75 3/4"
_

The first line includes the number of units mulled. UNIT SIZE is one individual unit’s size followed by “ - X”. Never use combined Exact Size as Unit Size. Rough Opening is the full mulled opening.

Separate mull

450 TWIN MULL ONLY

MULL SIZE: 0" x 71 1/2"
FOR LINES 1 AND 2
MULL OPENING: 1/2" x 72"
_

Do not label separate-mull dimensions Unit Size or Rough Opening.

Tags and notes

Preserve complete explicit notes, room/location, and window IDs in Tag, including A - BOTTOM - SMALL, B - TOP - SMALL, E - LEFT, and E - RIGHT. Preserve explicit notes such as BOTH SIDES OPERATE together with OX/XO when both appear in the source.

Other rules

Grille counts are per individual unit, not mulled combination. Combine sash/panel counts within one double-hung/slider unit. Preserve template formatting. Tax is No on every row. Store Rates at exactly two decimals. All examples are examples only.
