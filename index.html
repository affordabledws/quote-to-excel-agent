Quote-to-Excel Master Rules and Examples

Approved version: August 31, 2026

Purpose and source priority

Convert a new window or door quote PDF into the exact attached blank Excel template. Use sources in this order: (1) current user instructions, (2) new quote PDF, (3) approved manufacturer mappings, (4) reference quote only for expressly authorized uses, and (5) these master rules. The new quote controls products, models, quantities, product prices, operations, features, colors, hardware, screens, locations, and item order. Never guess.

Required files and template

Every conversion requires the new quote PDF and the exact blank Excel template. A reference PDF and markup percentage are optional. If either required file is missing, request only that file. Use the attached workbook as the output file and never create a replacement workbook.

Preserve the worksheet, table, headers, column order, formatting, fonts, fills, borders, widths, row heights, number formats, formulas, and workbook settings.

Approved columns in exact order: Channel SKU, Barcode, Item Name, Description, Qty, Rate, Tax, Tag. Leave Channel SKU and Barcode blank unless supplied. Set Tax to No unless explicitly taxable.

Order and reference

Process the complete quote in exact PDF line-by-line order. Never sort, alphabetize, regroup, or reorganize products. Create floor or section rows only when explicitly shown in the new quote or expressly authorized, and preserve their exact placement.

A reference may be used only for expressly authorized line layout, row-order style, floor organization and placement, Location or Tag naming style, overall workbook structure, and Delivery Charge amount. Never copy reference products, models, quantities, product prices, descriptions, Item Names, features, colors, hardware, screens, duplicates, or mistakes. Delivery Charge is the only reference price permitted, and only when expressly authorized. Never infer a room, floor, section, Tag, layout, or descriptive header from a reference unless expressly authorized.

Headers

Create separate HEADER rows for: (1) concise quote name, (2) concise general quote description, and (3) explicit or authorized floors and sections.

For each HEADER row: Item Name = HEADER; Description = header text; Qty and Rate blank; Tax = No; Tag blank.

The general header may include explicitly shown manufacturer, product category, exterior finish, general interior finish, Low-E, Argon, standard hardware, and NO SCREENS. Do not combine the quote name and general description. Do not write “WINDOWS PINE” before “UNFINISHED INTERIOR.”

Grouping

Keep each window, door, or assembly on one row. Combine each window with related hardware, screens, mulls, joining components, and accessories. Combine each door with related frames, panels, slabs, hardware, interior trim, exterior trim, screens, and accessories. The combined Rate must include every priced component belonging to the parent. Split only a truly independent separately priced product. Never combine different models, operations, product families, Tags, locations, or meaningful features.

Descriptions and features

Keep descriptions short, clear, and understandable. Include model, operation, and only necessary distinguishing details. Add TEMPERED, STANDARD, OBSCURED, BLINDS, and grille details only when explicitly shown, and assign every feature to the correct item or sub-unit. For grilles, include the actual pattern and W x H amount.

For mixed assemblies, preserve the exact model and operation order shown in the quote. For vertical assemblies use top-to-bottom order. Example: CXW25 LEFT-RIGHT STANDARD / AW231 STATIONARY-STATIONARY TEMPERED. Never imply the entire assembly has a feature when only one sub-unit has it.

Colors and hardware

Do not repeat specifications already covered by the general header. If only the interior color differs, write INTERIOR [COLOR]. If frame and panel interior finishes conflict, identify both, for example BLACK INTERIOR FRAME; UNFINISHED INTERIOR PANELS. Identify 100 Series interior colors when different. If hardware differs, mention only the differing hardware color. If a meaningful difference is unclear, stop and identify the affected lines.

Tags

Populate Tag only when the new quote explicitly provides a room, floor, area, location, section, grouping, or application. Use the exact wording or expressly authorized reference naming style. Never guess. If no location is provided, leave Tag blank.

Delivery and pickup

  • Explicit Delivery Charge: Item Name = DC; Description = DELIVERY CHARGE; Qty = 1; Rate = actual amount; Tax = No; Tag blank.
  • Explicit Pickup, Customer Pickup, Will Call, or similar with no delivery charge: Item Name = PICKUP; concise pickup Description; Qty = 1; Rate = 0; Tax = No; Tag blank.
  • If neither appears: Item Name = DC; Description = DELIVERY CHARGE; Qty = 1; Rate = 35; Tax = No; Tag blank.

Never calculate, add, or include freight, fuel surcharge, or a pickup charge above zero.

Markup

Apply markup only to product and assembly Rates. Never mark up HEADER, DC, or PICKUP rows. Calculate each marked Rate from the original Rate and round to cents. The marked product total after Qty multiplied by rounded Rate must never be below the exact requested markup, even by one cent. If the rounded total is short, increase an appropriate product Rate by the smallest cent adjustment needed. Never reduce another line.

Report original products, actual markup added, marked products, unchanged Delivery or Pickup, and final total.

Final review and math

Reconfirm every Item Name, mapping, model, operation, model order, operating-unit count, fixed-unit treatment, grouping, components, Qty, original Rate, marked Rate, Tag, floor placement, exact PDF order, special glass/features, grilles, colors, hardware, screens, missing items, duplicates, sorting, and reference use.

  1. Recalculate every line, including original Rate, component sum, markup, rounded Rate, Qty x Rate, and exact minimum markup.
  2. Independently total Qty x Rate for all product rows; calculate Delivery or Pickup separately.
  3. Reconcile original products + actual markup = marked products; marked products + unchanged Delivery or Pickup = final total.

All three checks must agree. Actual rounded markup must never be below the requested percentage.

Stop rule

Stop and identify the exact affected line for any missing or questionable mapping; unreadable model, Qty, or price; conflicting information; unclear parent, grouping, or feature placement; conflicting finish; unclear mixed-assembly order; possible duplicate; missing or inconsistent location; reference conflict; unexpected color or hardware difference; or anything that does not make sense. Never guess.

Filename and output

Base the completed workbook filename on the exact new PDF filename. Change only the extension to .xlsx and replace spaces with underscores. Return the completed workbook as an actual clickable .xlsx attachment. Do not return workbook contents, URL-encoded names, sandbox paths, or system paths.

Without markup, return only the workbook. With markup, return the workbook plus: Products: $[original] + $[actual markup] markup = $[marked products]; Delivery/Pickup: $[unchanged] unchanged; Final: $[final].
