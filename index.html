Quote-to-Excel Master Rules

Updated grille, mull, frame, screen, and mulled-unit rules

Header style

UNITED VINYL WINDOWS
NEW CONSTRUCTION, 3800 SERIES
WHITE EXTERIOR, WHITE INTERIOR
LOWE-2, SINGLE STRENGTH, ARGON
WHITE FLAT INTERNAL 5/8 COLONIAL GRILLES, UPPER GLASS ONLY, 3W2H PER UNIT, PANES
NAILING FIN, J CHANNEL
MULL [MULL TYPE], [MULL SIZE]
WHITE HARDWARE, WHITE HALF SCREENS
_

Use actual quote values only. For vinyl, always state NEW CONSTRUCTION or REPLACEMENT. Put all series on that line. Grilles go immediately below Glass. Frame-installation information goes below Grilles, then common Mull type/size, then Hardware/Screens. Final header line is exactly _.

Screens and hardware

Include common hardware type and common screen type in header. Rows show differences only. Screen wording is colored or uncolored FULL SCREENS/HALF SCREENS, or NO SCREENS. If screen color is not specified, omit the color. Never say “on operating units” or mention screen material.

Grilles

Grille counts are PER UNIT, not per mulled combination. For double-hung, slider, or similar units, combine the counts of all sashes/glass panels within that one unit. Identify PANES or BARS when explicit. Do not combine grille counts across separate units in a mull.

Rows and mulled units

Never write OVERALL UNIT SIZE. A regular unit uses UNIT SIZE. A mulled combination uses UNIT SIZE - X, where X is the number of units mulled together, such as UNIT SIZE - 3. Common frame, mull, hardware, screen, and grille details stay in the header; only row differences are repeated.

Other rules

Only floor headers; rooms in Tag. Preserve exact template formatting. Use exact spacing. Tax is No on every row. Store Rates at exactly two decimals. All examples are examples only; scan each PDF line by line.
