Quote-to-Excel Manufacturer Item Name Mappings

Approved version: August 31, 2026

Core rule: Numeric suffixes count operating units only. Fixed units do not count. Preserve the model and operation order shown in the new quote. If no listed product-type mapping fits, use the approved manufacturer default.

Examples

  • Operating casement + fixed + fixed + operating casement = casement count 2.
  • Andersen example above = ANDERSEN-C-2.
  • Pella example above = PELLA-C-2.
  • Sierra Pacific example above = SP-C-2.
  • Fixed-only items use the manufacturer default.

Mixed assemblies and attributes

Count operating units only for the applicable product type. Features such as TEMPERED, STANDARD, OBSCURED, BLINDS, grilles, colors, and hardware do not change the Item Name unless an explicit mapping says otherwise. Put each feature in the Description and assign it to the correct sub-unit. For vertical assemblies, preserve top-to-bottom order.

Other manufacturers

If the quote uses a manufacturer without an approved mapping, stop and ask only:

What Item Name rule should I use for this quote?

  • Manufacturer only
  • Manufacturer + Series
  • Manufacturer + Product Type
  • Custom mapping

Do not borrow another manufacturer’s mapping.

Validation

Reconfirm the manufacturer, WindowRama-to-Andersen rule, operating-unit count, fixed-unit exclusion, product type, approved suffix range, manufacturer default, model and operation order, and that no Item Name was copied from a reference unless independently correct for the new quote. If any mapping is questionable, stop and identify the exact line. Never guess.
