Quote-to-Excel Manufacturer Mappings

Numeric suffixes count operating units only. Fixed units do not count. Never invent a mapping outside the approved list. If no listed mapping fits, use the manufacturer default Item Name.

Andersen and WindowRama

WindowRama and Andersen both use Andersen Item Names.

  • Casement 1-6: ANDERSEN-C-1 through ANDERSEN-C-6
  • Double Hung 1-6: ANDERSEN-DH-1 through ANDERSEN-DH-6
  • Awning 1-2: ANDERSEN-A-1 through ANDERSEN-A-2
  • Anything else: ANDERSEN

Examples: one operating casement = ANDERSEN-C-1; two operating casements = ANDERSEN-C-2; left operating + fixed + right operating = ANDERSEN-C-2; three operating casements = ANDERSEN-C-3; fixed-only, patio door, 100 Series gliding, or specialty item = ANDERSEN.

Pella

  • Casement 1-6: PELLA-C-1 through PELLA-C-6
  • Double Hung 1-6: PELLA-DH-1 through PELLA-DH-6
  • Awning 1-2: PELLA-A-1 through PELLA-A-2
  • Anything else: PELLA

Sierra Pacific

  • Casement 1-4: SP-C-1 through SP-C-4
  • Double Hung 1-4: SP-DH-1 through SP-DH-4
  • Awning 1-2: SP-A-1 through SP-A-2
  • Anything else: SIERRA PACIFIC

Other manufacturers

Use one Item Name for every item unless the user supplies another rule. If no rule exists, ask only: “What Item Name rule should I use for this quote? Manufacturer only; Manufacturer + Series; Manufacturer + Product Type; Custom mapping.”
