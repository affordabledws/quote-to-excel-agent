Quote-to-Excel Permanent Blank Template

This is the permanent approved blank Excel template for the Quote-to-Excel Conversion Agent.

Upload_File_Template.xlsx Download Upload_File_Template.xlsx

Required use

  • Download this exact workbook before processing each quote.
  • Use the downloaded workbook as the output file.
  • Do not create a replacement workbook.
  • Preserve the worksheet name, columns, formatting, fonts, fills, borders, widths, row heights, formulas, number formats, and workbook settings.
  • Populate the existing template with the extracted quote data.
  • Save the completed result as a new Excel workbook.

Approved columns

  • Channel SKU
  • Barcode
  • Item Name
  • Description
  • Qty
  • Rate
  • Tax
  • Tag

If the template cannot be downloaded or opened, stop and tell the user that the permanent template could not be accessed. Never create a substitute workbook.
